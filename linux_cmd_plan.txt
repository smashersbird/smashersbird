🚀 7-Day Linux Mastery Plan (DevOps Focus)
🎯 Goal:
Strong command basics
Clear concepts
Real troubleshooting thinking
Interview confidence
📅 Day 1 – File System Basics
🔹 Learn:
ls, pwd, cd
touch, mkdir, rm, cp, mv
🔹 Practice:
mkdir test
cd test
touch file1.txt
cp file1.txt file2.txt
mv file2.txt new.txt
rm file1.txt
🎯 Target:

👉 Navigate Linux confidently

📅 Day 2 – Permissions & Ownership 🔐
🔹 Learn:
chmod, chown
rwx (7,6,5,4 logic)
🔹 Practice:
chmod 755 file.sh
chmod 700 file.sh
chown user:user file.sh
🎯 Target:

👉 Understand who can access what

📅 Day 3 – File Viewing & Search 🔍
🔹 Learn:
cat, less, head, tail
grep
find
🔹 Practice:
head -n 5 file.txt
tail -f file.txt
grep "error" file.txt
find . -name "*.log"
🎯 Target:

👉 Search files like a DevOps engineer

📅 Day 4 – Disk & System Monitoring 📊
🔹 Learn:
df -h
du -ah
top
ps -ef
🔹 Practice:
df -h
du -ah . | sort -rh | head -n 5
top
ps -ef | grep nginx
🎯 Target:

👉 Debug disk + process issues

📅 Day 5 – Process & Networking 🔥
🔹 Learn:
kill, pkill
netstat / ss
lsof
🔹 Practice:
ps -ef
kill <PID>
ss -tuln
lsof -i :8080
🎯 Target:

👉 Handle real production issues

📅 Day 6 – Archiving & Automation ⚙️
🔹 Learn:
tar, zip
crontab
🔹 Practice:
tar -czvf backup.tar.gz folder/
crontab -e

Add:

0 2 * * * echo "backup"
🎯 Target:

👉 Automation understanding

📅 Day 7 – Real Scenarios (MOST IMPORTANT) 🚀
Practice these:
🔥 Scenario 1:

Disk full → debug

Commands:

df -h
du -ah / | sort -rh | head -n 10
🔥 Scenario 2:

Permission denied

Check:

ls -l
ls -ld
🔥 Scenario 3:

High CPU

top
kill <PID>
🔥 Scenario 4:

SSH not working

Check:

.ssh
permissions
keys
